# FERDIV4 — Software Developer Portfolio

A responsive static developer portfolio built with HTML5, CSS3, and vanilla JavaScript. It is ready for GitHub Pages.

## Project structure

```text
ferdiv4-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    └── icons/
```

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For the best development experience, use VS Code with the Live Server extension (optional).

No build step, package installation, or backend is required.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com/) and create a new repository, for example `ferdiv4-portfolio`.
2. Upload the contents of this folder to the repository. Make sure `index.html` is in the repository root, not inside another nested folder.
3. Open the repository's **Settings**.
4. Select **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then save.
7. Wait for GitHub Pages to publish. The published URL will appear in the Pages settings.

## Personalize before publishing

- Replace the profile monogram in the About section with your own photo if you want. Put the image in `assets/images/` and update the `.profile-placeholder` markup in `index.html`.
- Update project descriptions and links in the Featured Projects section. The RCCG Bread of Life project currently links to `https://rccgbreadoflife.site.je/`; change it if needed.
- Add your email address or social profiles when you are ready.
- The contact form is intentionally static: JavaScript validates it and opens WhatsApp with the visitor's message. It does not send form data to a server.
- The Google Fonts import requires an internet connection; the site still works with the browser's fallback sans-serif font if fonts cannot load.
